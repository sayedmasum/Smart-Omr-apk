# APK বানানোর নিয়ম (কিছু ইনস্টল ছাড়া)
1. github.com এ নতুন repository খুলুন (যেমন smart-omr)।
2. এই ফোল্ডারের সব ফাইল (লুকানো .github ফোল্ডারসহ) আপলোড করুন।
3. Actions ট্যাব > "Build APK" চলতে দিন (৪-৬ মিনিট)।
4. শেষ হলে রানটি খুলে নিচে Artifacts থেকে "SmartOMR-apk" ডাউনলোড করুন, ZIP খুলে app-debug.apk ফোনে ইনস্টল করুন
   (ফোনে "Install unknown apps" অনুমতি দিতে হবে)।
